# PhysiCar 자율주행 프로젝트

PhysiCar 환경에서 카메라와 LiDAR 정보를 이용해 주행 경로를 추정하고, 신호등 인식·차선 추종·장애물 회피를 수행하는 Python 프로젝트입니다. 센서 기반 주행기와 시뮬레이터의 경로 정보를 사용하는 주행기를 함께 포함합니다.

## 주요 구현

- **카메라 기반 주행 영역 추정:** 영상의 색상·영역·차선 단서를 이용해 주행 중심과 전방 상태를 추정합니다.
- **LiDAR 기반 콘 감지와 회피:** 주변 거리 패턴에서 콘 후보를 찾고 조향·속도에 반영합니다.
- **선택적 카메라–LiDAR 결합:** 별도 검출 모델이 준비된 경우 카메라 검출과 LiDAR 거리를 연결합니다. 기본 설정에서는 해당 모델을 사용하지 않습니다.
- **주행 제어:** 도로 형태와 조향량에 따른 속도 조절, 출발 신호 대기, 센서 오류 처리를 포함합니다.
- **실행 관리:** 별도 실행 래퍼에서 로그 기록, 프로세스 관리, 종료 시 정지 명령을 처리합니다.

## 두 가지 실행 방식

| 구분 | 센서 기반 주행 | 시뮬레이터 경로 기반 주행 |
| --- | --- | --- |
| 주요 코드 | `autodrive.py`, `drive/` | `race/run.py`, `race/config.py` |
| 입력 | 카메라, LiDAR, 오도메트리 등 | 시뮬레이터의 경로·차량 상태·장애물 정보 |
| 주요 처리 | 영상 기반 주행 영역 추정, 센서 기반 회피 | 경로 추종, 곡률 기반 속도 계획, 장애물 회피 |
| 실행 대상 | 센서 API를 제공하는 환경 | 필요한 `/sim/api`가 제공되는 환경 |

`race/run.py`는 `PC_TARGET` 값으로 모드를 선택합니다. `sim`은 경로 기반 주행, `real`은 센서 기반 주행이며, 기본값 `auto`는 SIM API 응답 여부로 판단합니다. 센서 방식의 실차 설정은 `run_real.sh`에 정리되어 있습니다.

## 코드 구성

| 파일 | 역할 |
| --- | --- |
| `autodrive.py` | 센서 기반 자율주행 루프 |
| `drive/robot.py` | 카메라·LiDAR·IMU·오도메트리 조회 및 속도·조향 명령 |
| `drive/lane.py` | 주행 영역과 차선 단서 분석 |
| `drive/cones.py` | LiDAR 콘 감지 및 회피 계산 |
| `drive/fusion.py` | 선택적 카메라 검출 모델과 LiDAR 결합 |
| `drive/control.py` | 조향·속도 계산 |
| `drive/light.py` | 출발 신호등 인식 |
| `drive/health.py` | 센서 응답과 제어 루프 처리 시간 확인 |
| `race/run.py` | 모드 선택 및 시뮬레이터 경로 기반 제어 |
| `race/config.py` | 경로 추종·속도·장애물 회피 파라미터 |
| `run.sh` | 대회 환경의 고정 경로를 사용하는 진입점 |
| `t_run.sh` | 실행 대상 지정, 로그, 프로세스 종료를 처리하는 래퍼 |
| `run_real.sh` | 낮은 속도와 시간 제한을 적용한 실차용 실행 설정 |

## 실행 준비

Python 3와 Bash, 실행 중인 PhysiCar 서버가 필요합니다. 코드가 사용하는 기본 Python 패키지는 다음과 같습니다.

```bash
python3 -m pip install numpy opencv-python requests
```

카메라 콘 검출 모델을 사용할 때만 `ultralytics`와 별도의 모델 가중치가 추가로 필요합니다. 모델 가중치와 시뮬레이터 자체는 이 저장소에 포함되어 있지 않습니다.

## 실행 방법

아래 명령은 저장소 루트에서 Bash로 실행합니다. 실제 주행 전에 서버와 실행 대상이 맞는지 확인해야 합니다.

### 1. 시뮬레이터 경로 기반 주행

필요한 경로·상태 API를 제공하는 PhysiCar 시뮬레이터에서 실행합니다.

```bash
PC_TARGET=sim PC_ENTRY=race/run.py source ./t_run.sh
```

`run.sh`를 사용하는 환경에서는 저장소가 `/home/physicar/physicar_ws`에 있어야 합니다. 현재 `race/run.py`의 서버 주소는 `http://localhost`로 지정되어 있습니다.

### 2. 센서 기반 주행

```bash
PC_COURSE_AUTO=0 PC_MAX_SECONDS=60 source ./t_run.sh
```

이 명령은 기본 진입점인 `autodrive.py`를 실행합니다. `PC_COURSE_AUTO=0`은 콘 회피 모듈이 SIM 정보로 코스 설정을 자동 추정하는 기능을 끕니다. 카메라·LiDAR 등의 센서 API가 필요합니다.

### 3. 실차용 보수적 실행 설정

다음 명령은 연결된 차량에 주행 명령을 보냅니다. 차량과 주행 공간을 준비한 상태에서 실행합니다.

```bash
PC_REAL_CONFIRM=YES source ./run_real.sh
```

현재 스크립트의 기본 설정은 최대 속도 `0.65 m/s`, 실행 시간 `60초`, 출발 신호 대기입니다. 중단은 실행한 터미널의 `Ctrl+C`를 사용합니다.

## 자주 사용하는 설정

| 설정 | 용도 |
| --- | --- |
| `PC_TARGET` | `race/run.py`의 실행 모드: `sim`, `real`, `auto` |
| `PC_ENTRY` | `t_run.sh`가 실행할 Python 파일. 기본값은 `autodrive.py` |
| `PHYSICAR_URL` | 센서 기반 주행 API 주소. 기본값은 `http://localhost` |
| `PC_SPEED_MAX`, `PC_SPEED_MIN` | 센서 기반 주행의 속도 범위 |
| `PC_MAX_SECONDS` | 센서 기반 주행의 실행 시간 제한 |
| `PC_WAIT_GREEN` | 센서 기반 주행의 출발 신호 대기 여부 |
| `PC_CONE_MODEL` | 선택적 카메라 콘 검출 모델 경로 |
| `PC_COURSE_AUTO` | 콘 회피 설정에 SIM 코스 정보를 사용할지 여부 |
| `PC_LOG` | `t_run.sh`의 로그 파일 경로 |

경로 기반 주행의 제어 주기·속도·종료 시간은 `race/config.py`의 설정을 사용합니다. 센서 기반 주행의 환경변수가 두 방식에 모두 적용되는 것은 아닙니다.

## 참고 사항

- 이 저장소는 주행 코드입니다. 서버, 시뮬레이터, 실제 차량의 구동 환경은 별도로 준비해야 합니다.
- 경로 기반 방식은 시뮬레이터 내부 정보에 의존합니다. 센서 기반 방식과 입력 조건을 구분해서 결과를 해석해야 합니다.
- 코드 주석에 언급된 일부 `tools/` 실험 파일과 모델 가중치는 현재 공개 저장소에 포함되어 있지 않습니다.
- 이 문서는 공개 코드의 구성과 실행 경로를 설명합니다. 별도의 주행 결과나 대회 순위를 추가로 주장하지 않습니다.
